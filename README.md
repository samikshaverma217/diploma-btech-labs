# Diploma to BTech - Python Lab Series | Python for BTech

Complete Python Lab File Series for Diploma to BTech students - Covers BTech 1st Year to Final Year syllabus.

### 🚀 Live Repo: `diploma-btech-labs`

This repository contains 20+ practical programs covering basics to advance, made for Viva and Placement preparation.

### 📁 Repository Structure (8 Folders | 20+ Programs)

| Folder | Topic | Files | BTech Relevance |
| :--- | :--- | :--- | :--- |
| `01_basics/` | Python Basics | `01_hello_world.py` to `04_datatypes.py` | Sem 1 - Programming Fundamentals |
| `02_conditional/` | If-Else | `01_if_else.py`, `02_nested.py` | Sem 1 - Logic Building |
| `03_loops/` | Loops & Tables | `01_for_loop.py`, `02_while_loop.py`, `03_table_programs.py` | Sem 1 - Patterns & Logic |
| `04_file_handling/` | File Handling | `01_file_read_write.py`, `02_lab_data.py` | Sem 2 - Data Persistence |
| `05_numpy/` | NumPy | `01_numpy_basics.py` | Sem 3 - Data Science & AI |
| `06_pandas_matplotlib/` | Data Analysis | `01_pandas.py`, `02_matplotlib.py` | Sem 3 - Data Visualization |
| `07_database/` | Database | `01_mysql_connectivity.py`, `02_crud_operations.py` | Sem 4 - DBMS Lab |
| `08_oops/` | OOPs Concepts | `01_oops_basics.py` (Complete) | Sem 2 & 4 - Most Asked in Interview |

### 🔥 Key Concepts Covered

- **Core Python:** Variables, Data Types, Operators, Input/Output
- **Logic:** If-Else, Nested If, For/While Loops
- **Lab Based:** Table of 2, 6, 9, SI Calculation (P=120,R=4,T=2), Roll No 9,41,13,15
- **Advance:** File Handling, NumPy, Pandas, Matplotlib
- **OOPs:** Class, Object, Constructor Overriding, super(), Single, Multilevel, Multiple, Hierarchical, Hybrid Inheritance, Polymorphism, Encapsulation, Abstraction
- **Database:** MySQL Connectivity, CRUD Operations
